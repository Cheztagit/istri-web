# Buat Nadya cantiku

Jalankan: `npm install` lalu `npm run dev`. Build: `npm run build`.

Yang bisa kamu ubah sendiri:
- Nama: `src/config.ts` (NAME)
- Isi surat: `src/config.ts` (LETTER)
- Foto: taruh di `public/foto/` (lihat CARA-GANTI-FOTO.txt), keterangannya di `src/config.ts`
- Kartu: `src/cards.ts` (tiap kartu: tingkat 1 hangat, 2 panas, 3 nakal banget)
- Data paket dan resi: `src/data.ts`

- Kupon: `src/components/DashExtras.tsx` (COUPONS). Perkiraan sampai: ETA di file yang sama.
- Surat dibalik: `src/components/LetterModal.tsx`
